❓ Frequently Asked Questions
The extension isn't blocking trackers. What should I do?
Go to Settings tab → make sure "Ad Tracker Blocking" is turned ON. Try reloading the page after enabling it.
A website broke after installing the extension.
Go to Settings → Custom Block Domains and check if you accidentally blocked a necessary domain. You can also temporarily disable blocking in Settings.
My data disappeared after updating the extension.
Data is stored in your browser's local storage and should persist across updates. If data was lost, it may have been cleared by your browser. Always export a backup using the Export tab.
The export button doesn't work.
Make sure you have some data collected first (browse Google, YouTube, or shopping sites). Then try selecting at least one category and one data type before exporting.
How do I reset everything?
Go to Settings tab → scroll down → click "Clear All Data". This permanently removes all collected data. Consider exporting first.
Is there an Android app?
Yes! An Android app is currently in beta testing. Follow us on Bluesky for updates on the public release.
